# Excel Data Analyst Skill

An AI-assisted data analysis skill for Excel and CSV files, powered by Python.

## Features

- Excel and CSV file analysis
- Descriptive statistics
- Missing values detection
- Duplicate records detection
- Outlier detection
- Correlation analysis
- Data visualization
- Automated JSON reports

## Requirements

- Python 3.10+
- pandas
- numpy
- matplotlib
- openpyxl

## Project Structure

```text
excel-data-analyst/
├── SKILL.md
├── scripts/
│   └── analyze.py
└── examples/
    └── test_data.xlsx
```

## Usage

1. Install Python and the required dependencies.
2. Place your Excel or CSV file in the working directory.
3. Run the analysis script with your input file.
4. Review the generated JSON report and charts.

## Output

The skill generates:
- A JSON analysis report
- Statistical summaries
- Data quality insights
- Visualization charts
